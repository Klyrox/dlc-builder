1. Carica un DLC

Sezioni implementate (lettura/scrittura completa): HEADER, PAL, CEL, SPR, SEQ, MTR.

Sezioni nel file

SezioneDimensione (byte)Stato

Editor palette (PAL)

64 colori per palette. Ogni colore ha alpha binario (opaco/trasparente) — è così che funziona il formato del Furby.

Clicca uno swatch per modificarlo.

Celle occhi (CEL)

Sostituisci 4 celle da un'immagine 128×128

Carica un'immagine quadrata di 128×128 px (2×2 celle da 64×64). Verrà estratta una palette (max 64 colori) e i 4 quadranti diventeranno 4 nuove celle, assegnate agli indici scelti sotto. Se lasci gli indici vuoti, le celle vengono aggiunte in coda.

Sequenze (SEQ)

Ogni sequenza è una lista di parole a 16 bit (esadecimale). Il 4°→(n-1)° valore seleziona animazioni occhi; valori 0x8xxx/0xaxxx puntano ad animazioni specifiche. L'ultimo valore deve restare 0 (terminatore).

Playlist di frame (SPR)

16 playlist. Ogni playlist referenzia una lista di indici in "frames"; ogni frame combina 4 sotto-celle + palette. Modifica gli indici di frame_indices per cambiare quale grafica viene mostrata.

Frame (SPR) — editor puntuale

Cerca un indice di frame per modificare le sue 4 coppie [cella, palette]. Usato dagli hack tipo "sostituisci occhi/fiamme".

Tracce audio (AMF)

Encoder A1800/a18 eseguito nel browser via Pyodide (Python in WebAssembly) — nessun file audio lascia il tuo computer. Il primo utilizzo scarica il runtime Python (~10 MB) da un CDN.

Sostituisci o aggiungi una traccia

Carica un file audio (WAV, MP3, ecc.) — verrà ricampionato a 16 kHz mono e codificato in a18 a 20ms/frame, esattamente come il formato Furby.

Esporta nuovo .dlc

Ricostruisce header + sezioni (implementate + passthrough) in un nuovo file .dlc scaricabile.
